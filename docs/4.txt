#### **Accessibility & Technical Requirements**

* **Audit UI:** Any dashboard monitoring these agents must adhere to the **Visual Logic** rule: do not use color alone for status alerts. An "Exception" must be accompanied by an error icon and a clear text label (e.g., `[!] ALERT: Duplicate Entry`).
* **Non-Nested Constraint:** Ensure the `Surgeon` module's correction logic does not nest the original `Entry_ID` inside the new record's payload. Store as a separate reference field (`Original_Entry_Ref`).
